# Robot Manipulation Datasets + Simulators for dreamer4

> Living document maintained by the research subagent. **Status: v0 (compiled from model knowledge, cutoff Jan 2026 — figures still need web verification).** Web access (WebSearch/WebFetch) was denied on the first agent run; numbers marked approximate should be confirmed.

dreamer4 needs: RGB video sequences (for the tokenizer), temporally-coherent transitions (for the dynamics model), multi-task coverage, a runnable simulator with **headless offscreen rendering** for closed-loop eval, a permissive license, and a manageable footprint on an H200 cluster.

## Per-option highlights

- **LIBERO** — 4 suites (Spatial/Object/Goal = 10 tasks each + LIBERO-100). ~50 teleop demos/task, robomimic-style HDF5. Franka Panda in robosuite/MuJoCo. Obs: agentview + eye-in-hand RGB (128x128 default, re-renderable) + proprio + object states; 7-DoF OSC action. Headless via `MUJOCO_GL=egl`. Native, standard VLA eval (free baselines: OpenVLA etc.). Gotchas: pin robosuite/MuJoCo versions, set `MUJOCO_EGL_DEVICE_ID` on multi-GPU nodes. Refs: libero-project.github.io, arXiv:2306.03310.
- **robomimic/robosuite** — Lift/Can/Square/Transport/ToolHang; PH/MH/MG flavors. Same engine/eval/license as LIBERO. **Gotcha:** several official sets ship low-dim only — must replay through sim (`dataset_states_to_obs.py`) to materialize images. Fewer tasks than LIBERO. Refs: robomimic.github.io, arXiv:2108.03298.
- **Meta-World** — 50 Sawyer tasks, primarily an RL benchmark; **no human demos** (scripted experts only), **state-based by default** with plain backgrounds — weak as a turnkey video corpus. MIT, EGL headless. Refs: meta-world.github.io, arXiv:1910.10897.
- **CALVIN** — long-horizon, language-conditioned play data (richest video corpus here); 34 tasks, env splits D→D/ABC→D/ABCD→D. PyBullet + Franka, RGB-D static + wrist. Native chained 5-task LH eval. **Gotchas:** ABCD ~500 GB; wire up the PyBullet EGL renderer plugin. Refs: calvin.cs.uni-freiburg.de, github.com/mees/calvin, arXiv:2112.03227.
- **ManiSkill2/3** — SAPIEN/PhysX5; **ManiSkill3 GPU-parallelizes sim+render** → thousands of parallel envs, ideal for fast closed-loop eval + data gen on H200. Demo datasets provided (HDF5+JSON), RGB-D. **Gotcha:** Vulkan headless driver/ICD setup; MS2→MS3 API churn (pin a version). Pairs with SimplerEnv. Refs: maniskill.ai, maniskill.readthedocs.io, arXiv:2302.04659.
- **RLBench** — 100 tasks, Franka, CoppeliaSim/PyRep; demos generated by motion planner (cached PerAct-style 18-task subsets exist). **Biggest gotcha: needs X server → Xvfb for headless (no clean EGL)**, heaviest install, slow. CoppeliaSim EDU licensing. Refs: github.com/stepjam/RLBench, arXiv:1909.12271.
- **Open X-Embodiment** — best **large-scale pretraining** corpus (RLDS/TFDS, 22+ embodiments). No native sim; **SimplerEnv** gives real-to-sim closed-loop eval for the Bridge/WidowX and RT-1/Fractal subsets. Heterogeneous action/proprio → needs normalization; tens of TB full (use curated mixtures). Refs: robotics-transformer-x.github.io, github.com/simpler-env/SimplerEnv, arXiv:2310.08864.
- **DROID** — ~76k real Franka trajectories (~350h), high-res stereo — excellent tokenizer pretraining with one consistent embodiment. No aligned sim; eval is real-robot. RLDS ~1.7 TB. Refs: droid-dataset.github.io, arXiv:2403.12945.

## Top recommendation

1. **LIBERO + robosuite/MuJoCo (start here)** — lowest friction, clean dual-view RGB demos, 130 multi-task suites, native + easy EGL-headless closed-loop eval, MIT, and standard baselines to compare against. Fastest path to an end-to-end tokenizer→dynamics→sim-rollout pipeline.
2. **ManiSkill3 + SAPIEN** — when eval/data-gen throughput matters; GPU-parallel sim+render is a structural advantage on H200. Resolve Vulkan-headless once. Also unlocks SimplerEnv.
3. **CALVIN + PyBullet** — best for long-horizon, language-conditioned, play-style video; costs are ~500 GB download and EGL-plugin wiring.

**Pretraining (orthogonal):** OXE (curated mixture) and/or DROID to pretrain the video tokenizer at scale, then fine-tune + closed-loop-eval in LIBERO/ManiSkill (SimplerEnv for OXE Bridge/Fractal embodiments).

## Minimal POC

LIBERO-Object or LIBERO-Spatial (10 tasks, ~500 demos), single H200:
1. Download suite HDF5; re-render agentview+wrist RGB at the tokenizer's resolution.
2. Train tokenizer, check reconstructions.
3. Train action-conditioned dynamics (7-DoF), verify multi-step latent rollouts decode.
4. Closed-loop eval with `MUJOCO_GL=egl` (+ `MUJOCO_EGL_DEVICE_ID`), report per-task success over N seeds.
5. Scale to LIBERO-90/130, then optionally port eval to ManiSkill3 and/or add OXE/DROID pretraining.

**Top pick: LIBERO + robosuite/MuJoCo.**

## VERIFIED — LIBERO chosen (2026-06-08)

**Dataset sizes** (HF repo `yifengzhu-hf/LIBERO-datasets`, HDF5, queried via HF API):

| Suite | Size | Tasks | Role |
|---|---|---|---|
| libero_spatial | ~7.5 GB | 10 | single-suite (spatial) |
| libero_object | ~7.8 GB | 10 | single-suite (object) — good POC |
| libero_goal | ~7.5 GB | 10 | single-suite (goal) |
| libero_10 (Long) | ~13.4 GB | 10 | long-horizon eval |
| **libero_90** | **~67.4 GB** | 90 | **main multi-task training suite** |
| **Total** | **~103.6 GB** | 130 | |

Recommended pull: multi-task train+eval = `libero_90 + libero_10` ≈ **81 GB**; quick POC = `libero_object` ≈ 7.8 GB. Download via `infra/download_libero.py` (HF `snapshot_download`, resumable, suite-selectable). Note: these HF sizes are larger than the LIBERO paper's compressed figures (1.7–3.4 GB/suite).

**Env / sim feasibility — smoke-tested locally (Python 3.10 / torch 2.9.1+cu128, RTX 3060):**
- dreamer4 + robosuite **coexist in one env**; robosuite pins **numpy<2** (→1.26.x), which dreamer4 tolerates. torch untouched.
- **robosuite 1.5.2 + mujoco 3.9.0 headless EGL offscreen render works** (128×128 agentview, 7-DoF rollout). Set `MUJOCO_GL=egl` (+ `MUJOCO_EGL_DEVICE_ID` on multi-GPU nodes).
- dreamer4 `DynamicsWorldModel(num_continuous_actions=7)` ingests LIBERO-shaped (RGB video + 7-DoF) batches (forward+backward OK).
- **Compatibility caveat:** canonical LIBERO historically pins `robosuite==1.4.1`. Standalone robosuite 1.5.2 render is verified, but LIBERO's bddl task suites must be confirmed on 1.5.x; fallback is a separate eval env (`robosuite==1.4.1`, `mujoco==2.3.*`, `numpy<1.24`). Training on HDF5 demos needs no simulator.

Cluster scripts: `infra/update_cluster_env.sh` (conda env update), `infra/download_libero.py` (dataset).
